Recipes

Servants

The exception

Go for everything.
Zig only by exception.

Zig enters in one case: a proven native need — a profiled hot kernel, a codec, an OS integration. Everything else stays Go. The burden of proof is on the native case, and the kernel is removable in minutes.

Start here

Run. Ship. Summon.

One install puts the binary and the MCP on your PATH. Then you talk to your agent.

  1. 01

    Install the binary

    • Needs curl and git.
    • Puts gogogo and gogogo-mcp in ~/.local/bin.
    curl -sSfL https://raw.githubusercontent.com/calionauta/gogogo/master/install.sh | sh

  2. 02

    Wire your agent

    • One entry in your client config — the MCP is the surface you use.
    • Clients spawn without a shell: use an absolute path, not ~.
    { "mcpServers": { "gogogo": { "command": "/home/you/.local/bin/gogogo-mcp" } } }

    Save as .mcp.json in your project, or run claude mcp add gogogo -- ~/.local/bin/gogogo-mcp.

    [mcp_servers.gogogo]
command = "/home/you/.local/bin/gogogo-mcp"

    In ~/.codex/config.toml (every project) or .codex/config.toml (this project).

    opencode mcp add gogogo -- ~/.local/bin/gogogo-mcp

    Or in opencode.json: "mcp": {"gogogo": {"type": "local", "command": ["/home/you/.local/bin/gogogo-mcp"]}}.

    pi mcp add gogogo -- ~/.local/bin/gogogo-mcp

    Pi reads the standard mcpServers format too — migrating from another client just works.

  3. 03

    Ask for what you want built

    • Your agent calls advise_stack first — it answers whether this should be gogogo at all.
    • Then it shows you the plan and asks for name, owner and languages before writing anything.

  4. 04

    Prefer a shell?

    • The CLI runs the same engine as the MCP — same plans, same proofs.
    • Ask, preview, then apply with the name and owner you chose.
    gogogo advise --need "an internal tool with logins and a dashboard"
gogogo --name my-app --owner my-org --dry-run --format json
gogogo --name my-app --owner my-org --yes

  5. 05

    Just want to see it run?

    • Scaffold into a scratch directory and boot it.
    • Then open localhost:8080.
    gogogo --run
