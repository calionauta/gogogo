What makes it different

Everything async your app will need.
Already inside.

Every web app eventually needs a queue, a workflow runtime, a collaboration layer, and a realtime layer. They solve different problems, so gogogo compiles all of them into one build — and lets you switch each off with a single environment variable when you don't need it.

Background jobs that update the UI

goqite + SSE Hub

Always on. Work longer than ~50ms goes here instead of blocking a request — progress streams back to the browser.

Workflows that survive a restart

DagNats over JetStream

Declarative JSON. Kill the server mid-run; it resumes at the last incomplete step.

Collaboration without data loss

Loro CRDT

Offline edits merge with no last-write-wins loss. Ops converge idempotently.

Live record updates, scoped per user

PocketBase realtime

The collection's own access rules decide who sees what — no extra channel to secure.

Ephemeral UI signals

SSE Hub over Datastar

Toasts, client counts, workflow progress — signals, not database-shaped events.

Broadcast across instances

NATS JetStream

Run two or more instances behind a load balancer and records converge. Safe to enable on one.

Safe to trim

Delete what you don't need, without guessing.

Every file in the codebase carries a SCOPE annotation on two axes: where it lives, and what happens if you delete it. A linter enforces it, so you never have to guess whether a directory is load-bearing.

Core

The binary does not work without it.

config · db · internal/queue
internal/secrets · features/app
router · web/resources

Customize, never remove.

Plugin

The binary works but loses a capability.

internal/nats · internal/dagnats
internal/llm · internal/collab
internal/datastar · web/skins

Swap, or delete + remove the wiring call.

Feature

A demo or add-on.

features/landing · features/config

Keep as reference, then remove.

The exception

Go for everything. Zig only as an exception.

Zig enters in one case: a proven native need — a profiled hot kernel, a codec, an OS integration. Everything else stays Go.
