What makes it different

Most templates make you pick one async strategy.
This one ships six.

Every web app eventually needs a queue, a workflow runtime, a collaboration layer, and a realtime layer. They solve different problems, so gogogo compiles all of them into one build — and lets you switch each off with a single environment variable when you don't need it.

goqite

background jobs + SSE hub

Always on. Work that takes more than ~50ms goes here instead of blocking a request.

DagNats

durable multi-step workflows

Declarative JSON over JetStream. Kill the server mid-run; it resumes at the last incomplete step.

Loro CRDT

conflict-free collaborative state

Offline edits merge with no last-write-wins data loss. Ops converge idempotently.

PB realtime

record-change push

PocketBase's native channel, scoped per user by the collection's own access rules.

SSE Hub

ephemeral signals

Toasts, client counts, workflow progress — over Datastar's SSE protocol, not database-shaped.

JetStream

cross-instance broadcast

Run two or more instances behind a load balancer and records converge. Safe to enable on one.

Six layers, one make build. No build tags, no stub files, no matrix. Read the async layers doc →

In the box

Every choice already made.

Eleven decisions you would otherwise make in the first week — picked, wired together, and explained. Each one is documented with its trade-offs in stack layers.

Database · auth · API

PocketBase

Embedded SQLite with zero-config auth, REST and an admin UI at /_/. No separate service to run.

Templating

Templ

Type-safe Go components, generated at build time. A broken template is a compile error.

Reactive UI

Datastar over SSE

Server-rendered HTML with a ~12 KiB client. No JS framework, no bundler.

CSS · skins

DaisyUI v5 + Tailwind v4

Three skins compiled in, switchable at runtime with UI_SKIN or ?skin=.

Task queue

goqite + SSE Hub

Background jobs with retry and backoff, streamed to the browser. No Redis.

Durable workflows

DagNats

Multi-step workflows as declarative JSON over JetStream. Kill the process mid-run and it resumes.

Collaboration

Loro CRDT + Rough.js

Conflict-free shared state that merges offline edits with no last-write-wins loss.

LLM

GoAI

Any OpenAI-compatible provider behind an injectable interface, plus optional credits and BYOK billing.

Secrets

age + ~/.secrets/

Encrypted at rest, decrypted at boot. No vault, no cloud dependency.

Desktop · mobile

Wails v3 + gogpu/ui

Native shells over the same backend, and a native window with no HTTP at all.

Linting

golangci-lint (27) + datastar-lint

Tuned for LLM-authored code: unchecked errors, context leaks, lost propagation.

Out of the box

Capabilities, and how to switch each one off.

Every capability is always compiled. The headline is the feature you keep or delete; the quiet label underneath names the technology that powers it. Infrastructure opts out with an environment variable; product features opt out by deleting a package and its one wiring call. The installer asks which ones you want and trims the rest.

Auth

Powered by PocketBase

Cookie sessions, demo login, and per-request user loading. Middleware stays; the login UI is removable.

Todo app + realtime

Powered by PocketBase realtime + SSE Hub

Full CRUD. Database actions stream per user through the collection's access rule. Toasts, client count, and AI suggestions ride the ephemeral SSE Hub.

Background jobs + retry

Powered by goqite + retry-go

Jobs with exponential backoff and jitter. A retry emits a lastRetry signal so the UI can show "retrying…".

Durable workflows

Powered by DagNats over JetStream

WelcomeOnboarding creates example todos as declarative JSON. Stop the process mid-run and restart — it picks up where it left off. Off with DAGNATS_ENABLED=false.

Collaborative whiteboard

Powered by Loro CRDT + Rough.js + NATS

Conflict-free canvas with presence cursors, offline outbox replay, and PocketBase-persisted snapshots.

Hybrid offline sync

Powered by Service Worker + NATS Leaf Node + idempotency

Web clients queue mutations in IndexedDB and replay on reconnect; desktop edges replicate over NATS. Server-side idempotency means replays never duplicate. Off with OFFLINE_SYNC_ENABLED=false.

Three pluggable skins

Powered by DaisyUI + Basecoat + Morpheus

DaisyUI (default), Basecoat, and Morpheus — all compiled into the same binary, switchable per process (UI_SKIN) or per request (?skin=).

AI suggest + credits

Powered by GoAI + ai-credits (BYOK)

Todo suggestions behind an injectable LLM interface, optionally metered with a reserve/settle ledger, monthly entitlements, and encrypted per-user keys. Off when no key is set.

Admin surfaces

Powered by PocketBase admin + config view + DagNats console

Admin UI at /_/, read-only config at /config, and the workflow console — all from one binary.

Safe to trim

Delete what you don't need, without guessing.

Every file in the codebase carries a SCOPE annotation on two axes: where it lives, and what happens if you delete it. A linter enforces it, so you never have to guess whether a directory is load-bearing.

Core

The binary does not work without it.

config · db · internal/queue
internal/secrets · features/app
router · web/resources

Customize, never remove.

Plugin

The binary works but loses a capability.

internal/nats · internal/dagnats
internal/llm · internal/collab
internal/datastar · web/skins

Keep as reference, then remove.

Start here

Answer four questions. Ship it.

The installer scaffolds your repo from this template, renames it, and trims the plugins and features you skip. Nothing to install first except Go.

go run github.com/calionauta/gogogo/cmd/gogogo@latest
cd my-app
make dev

1

Name your project

Project name + GitHub owner. Sets the module path, binary, container and deploy directory — then compiles, so a half-renamed tree can't slip through.

2

Pick plugins + features

Durable workflows, whiteboard, landing, config view, credits, sounds, extra skins. What you skip is deleted with its wiring call, not left as dead code.

3

Run it

Live reload on localhost:8080. The demo is at /todo — sign in as demo@demo.app / demo.
