# Migrating to v0.44.0, the flat stack

v0.44.0 is the release where the framework layer left. A tree scaffolded before
it needs a port, not a rename, so work in commit order and run the gates after
each step.

## What the release removed

- `db/` — the app handle, the seeds and the idempotency hook
- `router/`, `internal/routeutil`, `internal/collabpb` — route wiring
- `features/store` — the two data-layer strategies behind `ENTITY_STORE`
- `features/auth` — the framework middleware; `internal/auth` owns identity
- each feature's second handler pair (todo, notes, whiteboard, room, landing,
  genui, config, chat, credits) — the chi slices replaced them
- `spikes/` and the `pb_data` fixtures

## What replaced each of them

| removed | now |
|---|---|
| app handle and seeds | `internal/db` (Turso) with `internal/dbschema/migrations/*.sql` |
| data access | sqlc sources in `internal/db/queries/`, generated into `internal/db/sqlcgen` |
| `ENTITY_STORE` strategy switch | none — handlers call `dbgen.*` directly |
| framework middleware identity | `internal/auth`: argon2id, opaque sessions, `gogogo_auth` cookie |
| framework realtime subscriptions | the `internal/queue` SSE hub, with JetStream for cross-instance |
| route wiring | `internal/server/chi.go` (`BootChi` + `buildChiMux`) |

## Order that works

1. Put the data layer in first: add `internal/db` with migrations and sqlc, and
   move each feature's queries onto `dbgen.*`.
2. Replace the identity middleware with `internal/auth` and mount its routes on
   the chi mux.
3. Move the handlers to `features/<name>/handlers/` and register each router in
   `internal/server/chi.go`.
4. Move realtime from subscriptions to the SSE hub, and add the JetStream path
   when you want cross-instance fan-out.
5. Delete the framework paths listed above, then `go mod tidy`: that is what
   drops the module.
6. Drop `ENTITY_STORE` and any config key only the old layer read.

## Gates

Every step ends with `gogogo --check --dir .`. The port ends with
`make check-scope && make check-docs` and `make ci-local-fast`. Behaviour the old
layer's tests pinned is re-pinned on the new slice, and the release commit body
lists those contracts: todo cross-session create, notes caret atomicity,
whiteboard peer counts, room presenter lock, chat persistence.

## After the port

Bump `scaffolded-from:` in `AGENTS.md` to `calionauta/gogogo@v0.44.0`. Nothing
rewrites that line for you.
